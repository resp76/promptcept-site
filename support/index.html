PromptCept Support

PromptCept works locally and does not require an account.

Common questions

Where are my prompts?

They are stored on the device. Use Settings → Export Prompts to create a portable JSON backup.

How do I restore a backup?

Open Settings → Import Prompts and select a PromptCept JSON backup.

Why didn’t my selected AI app open?

Install the selected assistant or use the website fallback. PromptCept copies the prompt; paste it into the assistant and send it yourself.

How do I delete my data?

Use Settings → Delete All Saved Prompts. Uninstalling also removes app-local data.
